# Calculadora de Impacto del Alza de Carburantes — Bolivia 2025

## Descripción
Simulador web interactivo que permite calcular el impacto económico mensual 
del alza de carburantes en Bolivia, producto del Decreto Supremo 5516 
aplicado a finales de 2025.

## ¿Qué hace?
El usuario selecciona su tipo de vehículo, cuánto carga y con qué frecuencia. 
La calculadora muestra cuánto pagaba antes, cuánto paga ahora y cuánto más 
gasta al mes según los precios oficiales de YPFB y ANH.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Datos utilizados
- Precios oficiales YPFB / ANH vigentes 2026
- Decreto Supremo 5516 (eliminación de subsidios al carburante)
- Inflación acumulada 2025: 24,86% — fuente: BCB / PNUD
- Inflación a 12 meses junio 2026: 15,05% — fuente: BCB
- Alza gasolina especial: +86,1% (3,74 → 6,96 Bs/L)
- Alza diésel: +163% — fuente: Growth Lab Harvard
